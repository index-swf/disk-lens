4. Plan B's streaming progress events + Plan C's comprehensive error handling are both essential

    53→### 2B. USN 日志扫描（主引擎）
    54→文件：`src-tauri/src/scanner/usn.rs`

    56→- 使用 `windows-rs` 的 `CreateFileW` 打开卷句柄（`\\.\X:`），传入 `FILE_FLAG_BACKUP_SEMANTICS` + `FILE_READ_ATTRIBUTES`（不需要管理员权限）
